# Oracle JET VDOM training sample app (2.0.0)
Example code for learning Oracle JET Virtual DOM Architecture based applications.

This project is developed for use with the Oracle JavaScript Extension Toolkit(JET) coding environment.

## Prerequisites
  * JET v19.0.x or higher is required for this project to work. Using the current production release is always recommended.
  * Nodejs v22 LTS or higher LTS is required.  Nodejs nightly(Current) releases may not work correctly. 

## Installation

* Clone project
* Change to the root directory of the project
* run *npm install*
* run *npx ojet serve*
