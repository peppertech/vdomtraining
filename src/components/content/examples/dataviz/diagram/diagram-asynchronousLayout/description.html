A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This example demonstrates JET Diagram component with asynchronous layout

  • Edit layout delay to experiment with delay timer. As the delay timer value is changed, the diagram will be rerendered with updated nodes and layout will be called with the specified value for the delay. Each time the layout will use different direction to position nodes - clockwise or counter-clockwise.
