1. Create an oj-diagram element.
  2. Provide nodes and links data for the component by constructing data providers out of nodes and links arrays.
  3. Supply a layout that positions nodes and links synchronously or asynchronously. Asynchronous layouts should return a Promise object that resolves when the layout is done.
  4. Accessibility : The application is responsible for populating the short-desc attribute with meaningful descriptors as the component does not provide a default descriptor.
  5. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
