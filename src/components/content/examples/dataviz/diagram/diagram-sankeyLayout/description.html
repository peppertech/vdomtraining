A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This demo shows how to build a Sankey diagram. Sankey diagrams demonstrate a flow from one set of values to another. The flow is represented by links and the width of each link is proportional to the flow quantity. Use it when the data represent a flow from one stage to another and you would like to illustrate how the flow is distributed between stages.
