A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

The demo showcases the usage of the oj.DiagramUtils.getLayout helper function. The helper function generates a layout callback function from a JSON object that contains positions for nodes, paths for links and layouts for labels.

This demo uses the D3 tree layout to process hierarchical data, generate nodes and links, assign position to each node and calculate a path for each link. See "Radial Dendrogram" on Mike Bostock's site .

Data shows the oj.baseComponent class hierarchy.
