1. Create an oj-diagram element.
  2. Create JSON object with nodes and links properties that correspond to the diagram nodes and links. Populate position for nodes and path for links. Pass the object to the getLayout() helper function on oj.DiagramUtils object.
  3. The coordinates and path could be generated using an external layout as demonstrated in the example.
  4. Accessibility : The application is responsible for populating the short-desc attribute with meaningful descriptors as the Diagram does not provide a default descriptor.
