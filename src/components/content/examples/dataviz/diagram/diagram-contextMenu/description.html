A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This demo shows how to trigger context menus on diagram background, nodes and links. Right click anywhere in diagram and select an action. The context menus can also be accessed by keyboard. Press Shift + F10 to open the context menu after navigating to an item. Select one of the actions by navigating to it and pressing Enter.
