1. The link creation operation will be initiated from a connection point ( port ), which is identified by the specified selector. The drop will be accepted by a drop port, which is also identified by the specified selector. See drag.ports.selector and drop.ports.selector for more details. Ports might be created as a part of a diagram node by a custom renderer or a node itself might be marked as a port .
  2. To configure drag ports for link creation, mark a node or an element on a node as a port and set the dnd.drag.ports property according to the API doc .
  3. To configure drop ports for link creation, mark a node or an element on a node as a port and set the dnd.drop.ports property according to the API doc .
  4. Accessibility : The application is responsible for providing the equivalent link creation functionality via context menu for accessibility reasons.
