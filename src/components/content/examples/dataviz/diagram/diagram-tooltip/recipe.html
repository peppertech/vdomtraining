1. Create a tooltip function that takes a dataContext argument. The dataContext contains information on the hovered item, including id , type and label of the hovered item. It also contains the tooltip parentElement , which the function can modify directly. The function should construct and return the desired tooltip string or a DOM element.
  2. Pass the function to the diagram tooltip.renderer property. The diagram will then call the function on hover to generate the tooltip and append the returned object to itself.
  3. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
