A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This demo shows how to render custom SVG content for Diagram nodes using the nodeContentTemplate slot and Diagram links using the linkContentTemplate slot. The same template is used for rendering the initial content and for creating custom selection, hover and focus effects. The same slots are used when the states change and the appropriate state is indicated by the state property in the slot's context for the node or context for the link .

You can also add data-oj-zoom-thresholds attribute to the nodeContentTemplate to set thresholds that will trigger a rerender when crossed. For example, additional text content will be shown when zooming in this demo. See the nodeContentTemplate doc for more details.

Use the oj-diagram-child-content element to indicate where the child content of a container node should be. Diagram will replace this element with the child contents of the container node.
