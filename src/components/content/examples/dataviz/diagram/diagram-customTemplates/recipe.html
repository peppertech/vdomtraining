1. To customize node content
    1. Create a template element with the slot attribute set to nodeContentTemplate .
    2. Populate the template element with the desired HTML content.
    3. Template content will have access to a RendererContext via the $current property as well as via any data-oj-as alias provided on the template element.
    4. To customize hover, selection and keyboard focus effects for the node:
      1. Modify the contents of the template based on the node's state which is passed via the context.
    5. Add data-oj-zoom-thresholds attribute to the template to set thresholds that will trigger a rerender when crossed. This should be a JSON array containing values between the min-zoom and max-zoom attribute values.
    6. To position child node content, add an oj-diagram-child-content element. Diagram will replace this element with the child contents of the container node.
  2. To customize link content
    1. Create a template element with the slot attribute set to linkContentTemplate .
    2. Populate the template element with the desired HTML content.
    3. Template content will have access to a LinkRendererContext via the $current property as well as via any data-oj-as alias provided on the template element.
    4. To customize hover, selection and keyboard focus effects for the link, modify the contents of the template based on the link's state which is passed via the context.
  3. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
