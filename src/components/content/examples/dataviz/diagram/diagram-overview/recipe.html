1. To display an overview window on JET Diagram use overview attribute with rendered equals 'on'.
  2. To customize an individual node in the overview window use overview.icon attribute on oj-diagram-node element.
  3. Accessibility : The application is responsible for populating the short-desc attribute with meaningful descriptors as the component does not provide a default descriptor.
  4. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
