A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This demo shows how to configure the overview window rendered within the Diagram.
The panning attribute specifies the pan behavior of the Diagram component.
  • "fixed" : panning is restricted to the visible region when the diagram is rendered at minZoom.
  • "centerContent" : panning is restricted based on the current zoom level to allow any area of the content to be centered. If an overview is being rendered, the overview.fit-area attribute should also be set to 'content' in most situations.
  • "none" : panning is not allowed.
The overview.fit-area attribute specifies the region that will be scaled to fit within the overview.
  • "canvas" : the canvas (the pannable area when the diagram is at minZoom) will be scaled to fit within the overview. The diagram panning attribute should also be set to 'fixed' in most situations.
  • "content" : the bounding box of the Diagram nodes will be scaled to fit within the overview.
The preserve-aspect-ratio attribute controls how the fit area is scaled within the overview.
  • "none" : the aspect ratio of the fit area may not be preserved as it is scaled to fit the overview.
  • "meet" : the aspect ratio of the fit area will be preserved as it is scaled to fit the overview.

The overview.valign and overview.halign attributes allow the position of the overview window to be configured.
