1. Create an oj-diagram element.
  2. Create an ArrayTreeDataProvider from an array of data, or a JSON source and use data binding to bind to the 'node-data' attribute.
  3. Create an ArrayDataProvider from an array of data, or a JSON source and use data binding to bind to the 'link-data' attribute.
  4. Create a template element with the slot attribute set to nodeContentTemplate . To use non-svg html elements in the node, use the foreignObject element. See the Custom Templates demo for details on how to use nodeContentTemplate .
  5. Accessibility : The application is responsible for populating the aria-label attribute on the component and short-desc attribute on the diagram nodes/links with meaningful descriptors. The application is also responsible for making sure any custom content meets accessibility requirements.
  6. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
