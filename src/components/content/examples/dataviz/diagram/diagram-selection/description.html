A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

The selection-mode feature allows a user to focus on a specific node or link by clicking on it.

  • By default, diagram selection is disabled - the selection-mode attribute is set to 'none'
  • When selection-mode is set to 'single' , selection of one item (node or link) is enabled.
  • When selection-mode is set to 'multiple' , selection of more than one item at a time is enabled. On desktop, select multiple items by holding the Ctrl key.
