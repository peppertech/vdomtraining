A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

The panDirection attribute allows the user to restrict panning to either the horizonal or vertical direction.

  • By default panDirection is 'auto' - allowing panning in both vertical and horizontal direction.
  • When panDirection is 'x' - panning is only allowed in the horizontal direction.
  • When panDirection is 'y' - panning is only allowed in the vertical direction.
  • panDirection setting may be useful if layout is predominantly horizontal or vertical.
