1. Look at the Basic demo to see how to create an oj-diagram.
  2. Set panning and zooming attributes to 'auto' .
  3. To set the zoom and center, modify pan-zoom-state.zoom, pan-zoom-state.center-x, and pan-zoom-state.center-y properties of the pan-zoom-state attribute.
  4. By default, the pan-zoom-state is reset to zoom-to-fit on property changes and component resizes. To prevent this reset, call event.preventDefault() on the oj-before-pan-zoom-reset event.
