A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This demo shows how to use the following features:

  • Programmatically set the pan zoom state by using the input controls. The x, y coordinates in the diagram nodes represent the upper left corner of the node in the layout coordinate space.
  • Toggle the 'Enable Prevent Default on beforePanZoomReset' checkbox to prevent the default reset behaviour. The default reset behaviour of the panZoomState is zoom to fit for option change. Click on the 'Add/Remove Nodes' button to see the panZoomState reset/not reset.
