A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

This demo shows the Drag and Drop between two Diagrams.

  • Drag nodes between diagrams.
  • Drag a node to a link on Diagram B to insert or reposition the node and split a link into two.
  • Drag a node to a node on Diagram B to insert or reposition the node and create a link between a dragged node and a target node.
