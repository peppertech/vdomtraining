• To customize nodes
    1. To create custom SVG content for the diagram node, provide a callback function using the node-content.renderer attribute on oj-diagram element. Check the expanded state of a node to make a decision, if the node should be rendered expanded or collapsed.
      When a custom renderer is called to render a container node, the renderer is responsible for appending child content element to the DOM created for the container node.
      When custom node renderer is called, the default expand/collapse buttons will be added to the node unless they are explicitly hidden using show-disclosure attribute on the node.
    2. To customize hover, selection and keyboard focus effects for the diagram node with custom content provide callback functions using the  node-content.hover-renderer , node-content.selection-renderer and node-content.focus-renderer attributes on oj-diagram element.
  • To customize links
    1. To create custom SVG content for the diagram link, provide a callback function using the link-content.renderer attribute on oj-diagram element.
    2. Note, when the oj-diagram-link-path class is used as a marker for the path element Diagram is responsible for providing path commands as a value for d attribute. The path value will be created using link points populated by the Diagram layout.
    3. Link Animation : When the link shape is represented by a single path element and the element is marked by the oj-diagram-link-path class, Diagram is able to recognize the link path and animate it using built-in path transformation during data change animation.
      Fade-in animation will be used for other link elements.
  • Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
