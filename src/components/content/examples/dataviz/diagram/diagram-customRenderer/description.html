A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

  • This demo shows how to render custom SVG content for Diagram nodes and links using custom renderer functions. Separate functions might be used for rendering the initial content for the nodes and links and for creating custom selection and hover effects. The hover and select renderers are called when the corresponding states have changed and they simply modify the existing DOM content to add and remove hover/selection effects as needed.
