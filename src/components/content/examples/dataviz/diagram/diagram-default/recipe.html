1. Create an oj-diagram element.
  2. Create either an ArrayDataProvider or an ArrayTreeDataProvider from an array of data, or a JSON source and use data binding to bind to the 'node-data' attribute.
  3. Create an ArrayDataProvider from an array of data, or a JSON source and use data binding to bind to the 'link-data' attribute.
  4. Add templates with slot attribute set to 'nodeTemplate' and 'linkTemplate' inside your oj-diagram with oj-diagram-node and oj-diagram-link as the child element. Please see the doc for more details about the oj-diagram-node , oj-diagram-link elements or the nodeTemplate and linkTemplate slots.
  5. The demo shows how to use optional 'data-oj-as' attribute to set the alias for the $current context for each individual template.
  6. Accessibility : The application is responsible for populating the aria-label attribute on the component and short-desc attribute on the diagram nodes/links with meaningful descriptors.
  7. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
