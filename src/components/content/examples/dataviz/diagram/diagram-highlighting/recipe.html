1. You can set the categories array on component data items, if it is necessary. By default node and links ids are used as categories .
  2. To highlight items on initial render, use the highlighted-categories attribute on the oj-diagram element.
  3. You can also use link-highlight-mode and node-highlight-mode attributes to customize node and links highlighting behavior.
  4. Accessibility : The application is responsible for populating the short-desc attribute with meaningful descriptors as the component does not provide a default descriptor.
  5. Layouts : The application is responsible for providing the layout algorithm used by the Diagram.
