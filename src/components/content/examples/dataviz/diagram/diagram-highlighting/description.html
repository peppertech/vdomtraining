A diagram displays a set of nodes and the links between them. The node positions and link paths are specified by an application-provided layout function.

The highlighting feature allows a user to highlight nodes and links by using the highlighted-categories or hover-behavior attributes.

  • By default, highlighting on hover is disabled - the hover-behavior attribute is set to 'none'
  • When hover-behavior is set to 'dim' , all objects that belong to the same category as hovered item are going to be highlighted.
